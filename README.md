# 星匠 Starwright

把 AI 创作工具，做成能直接用的东西。

网站：https://starwright.xyz/

![星匠](assets/cover.png)

## 网站上有什么

- **小人乱斗**：原创横版一对一格斗游戏，在浏览器里直接开打，也提供 Windows 版下载。
- **模匠 Modelwright**：一键生成 3D 模型、直接送进 Unity 的 Windows 工具，提供下载。
- **星璇**：全站向导，点右下角的她可以获得帮助；也提供 Windows 桌宠下载，并展示由模匠生成的 3D 星璇。
- **即将推出**：AI 漫助手，把小说变成 AI 漫剧与短片。

第一版不需要注册，所有工具免费。站宠偏好保存在本机浏览器；网站托管服务的数据处理以站内隐私说明为准。

## 更新

本仓库用于公开网站介绍、链接与更新记录，不包含网站源码。每次网站有变化都会记在 [更新记录](CHANGELOG.md) 里；未发布的开发进度会单独标明，不代表网站已经上线这些功能。

星璇 0.3.1 的桌宠与站宠联动、资源优化和比例修复正在开发中。站宠更新仍在开发分支等待合并，尚未部署到正式网站；当前桌宠公开下载仍为 v0.2.0。详见更新记录的“未发布”部分，以及公开桌宠仓库的 [性能与比例审查](https://github.com/chenyihang98-pixel/andromeda-desktop-pet/blob/main/docs/PERFORMANCE-0.3.1.md) 和 [验证记录](https://github.com/chenyihang98-pixel/andromeda-desktop-pet/blob/main/docs/VALIDATION-0.3.1.md)。
