# 星匠 Starwright

把 AI 创作工具，做成能直接用的东西。

网站：https://starwright.xyz/

![星匠](assets/cover.png)

## 网站上有什么

- **小人乱斗**：横版一对一格斗游戏，浏览器里直接开打，也有 Windows 版
- **音序 Muse**：点一个场景，就能做出一段背景音乐。浏览器里直接用，也有 Windows 版
- **拾趣牌社**：十三种扑克和三种立直麻将，和一桌二次元牌友随时开局
- **模匠 Modelwright**：一张图生成 3D 模型，一键送进 Unity 的 Windows 工具
- **星璇**：全站向导，点右下角的她可以问路；也有 Windows 桌宠
- **还在做**：AI 漫助手，把小说变成漫剧和短片

不用注册，全部免费。
